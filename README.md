# Functory Homebrew tap

Formulae for the [Functory](https://functory.com) command-line tools.

```sh
brew tap functory/tap
brew install functory
```

Or in one line: `brew install functory/tap/functory`.

The formulae here are written by the Functory CLI release workflow on every
stable release. Each one downloads the approved release archive from
`https://downloads.functory.com/cli` and verifies its SHA-256 checksum. Do not
edit them by hand: a manual change is overwritten by the next release.
